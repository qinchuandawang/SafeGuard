# 诈骗克星小程序 - 系统整合文档

## 一、项目概述

诈骗克星是一款基于 AI 的微信小程序，用于检测和防范各类电信网络诈骗。

### 1.1 技术架构

```
┌─────────────────────────────────────────────────────────┐
│                      微信小程序前端                        │
│  ┌─────────────────────────────────────────────────┐  │
│  │  微信小程序 + TDesign 组件库 + 原生 API           │  │
│  │  - pages/         页面目录                         │  │
│  │  - utils/         工具函数                        │  │
│  │  - assets/        静态资源                        │  │
│  └─────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
                              │
                              ▼ HTTP/SSE
┌─────────────────────────────────────────────────────────┐
│                      Java Spring Boot 后端              │
│  ┌─────────────────────────────────────────────────┐  │
│  │  Spring Boot + Spring AI + MyBatis-Plus         │  │
│  │  - 音频检测 API (Wav2Vec2 模型)                  │  │
│  │  - 视频检测 API (XceptionNet 模型)                │  │
│  │  - 文本检测 API (大模型)                         │  │
│  │  - 模拟诈骗对话 API (SSE 流式输出)                │  │
│  └─────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
```

### 1.2 项目结构

```
fraud-killer/
├── app.js                    # 应用入口，全局方法和数据
```

## 三、后端 API 接口

### 3.1 接口基础信息

| 项目 | 说明 |
|------|------|
| 基础 URL | `https://api.fraud-killer.com` |
| 协议 | HTTPS |
| 数据格式 | JSON |
| 认证方式 | Header Token（可选） |

### 3.2 检测相关接口

#### 3.2.1 音频检测

```
POST /api/detection/audio
Content-Type: multipart/form-data

参数:
  - file: 音频文件（必填）

响应:
{
  "code": 200,
  "message": "success",
  "data": {
    "taskId": "uuid-string",      // 任务 ID，用于后续查询
    "status": "processing"
  }
}
```

#### 3.2.2 视频检测

```
POST /api/detection/video
Content-Type: multipart/form-data

参数:
  - file: 视频文件（必填）

响应: 同音频检测
```

#### 3.2.3 文本检测

```
POST /api/detection/text
Content-Type: application/json

参数:
{
  "text": "待检测的文本内容"
}

响应:
{
  "code": 200,
  "data": {
    "taskId": "uuid-string",
    "status": "processing"
  }
}
```

#### 3.2.4 综合检测

```
POST /api/detection/multi
Content-Type: application/json

参数:
{
  "audio": "音频路径（可选）",
  "video": "视频路径（可选）",
  "text": "文本内容（可选）"
}

响应: 同上
```

#### 3.2.5 异步任务查询

```
GET /api/detection/task/{taskId}

响应:
{
  "code": 200,
  "data": {
    "taskId": "uuid-string",
    "status": "completed",        // processing | completed | failed
    "result": {
      "type": "audio",           // audio | video | text
      "confidence": 0.95,        // 置信度
      "probabilities": {
        "real": 0.05,
        "fake": 0.95
      },
      "report": "检测到明显的AI生成特征...",
      "advice": ["建议1", "建议2"]
    }
  }
}
```

#### 3.2.6 SSE 任务流式查询（可选）

```
GET /api/detection/task/{taskId}/stream

响应: SSE 流式
data: {"progress": 50}
data: {"progress": 80}
data: {"status": "completed", "result": {...}}
data: [DONE]
```

### 3.3 模拟诈骗接口

#### 3.3.1 开始模拟

```
GET /api/simulate/start/{scriptId}

参数:
  - scriptId: 剧本 ID（police | relative | investment | online）

响应:
{
  "code": 200,
  "data": {
    "content": "诈骗分子的开场白...",
    "quickReplies": ["快捷回复1", "快捷回复2"],
    "streamUrl": "/api/simulate/stream/{sessionId}"
  }
}
```

#### 3.3.2 继续对话

```
POST /api/simulate/chat
Content-Type: application/json

参数:
{
  "scriptId": "police",
  "userInput": "用户的回复",
  "conversationHistory": "[历史对话 JSON]"
}

响应:
{
  "code": 200,
  "data": {
    "content": "诈骗分子的回复...",
    "quickReplies": ["快捷回复1", "快捷回复2"],
    "suspicionDelta": 10,
    "finished": false
  }
}
```

#### 3.3.3 结束模拟

```
POST /api/simulate/end
Content-Type: application/json

参数:
{
  "scriptId": "police"
}

响应:
{
  "code": 200,
  "data": {
    "analysis": "您的警觉性分析...",
    "tips": ["防骗要点1", "防骗要点2"]
  }
}
```

| # | 配置项 | 说明 |

1. **服务器域名配置**

## 五、页面功能说明

### 5.1 首页 (pages/index)

- 展示应用 Logo 和口号

- 文章列表

- 文章内容展示
- 相关推荐

## 八、已知问题和限制

### 8.1 功能限制

1. **文件大小限制**
   - 音频：最大 10MB
   - 视频：最大 50MB

2. **文本长度限制**
   - 单次检测最多 2000 字符

3. **对话轮次限制**
   - 模拟诈骗最多 10 轮对话

### 8.2 开发模式

当 `devMode: true` 时：
- 检测功能使用随机 mock 数据
- 模拟诈骗使用本地预设话术
- 不调用后端 API

### 8.3 兼容性

- 微信版本要求：≥ 7.0
- 基础库版本：≥ 2.8.0

## 九、部署流程

### 9.1 后端部署

1. 打包 Spring Boot 应用
2. 部署到服务器（建议使用 Docker）
3. 配置 Nginx 反向代理
4. 配置 HTTPS 证书
5. 配置数据库连接

### 9.2 前端部署

1. 修改 `app.js` 配置
2. 修改 `utils/request.js` 中的 `BASE_URL`
3. 执行 `npm run build`（如使用构建工具）
4. 微信开发者工具上传代码
5. 提交审核

### 9.3 服务器要求

| 项目 | 最低配置 |
|------|----------|
| CPU | 2 核 |
| 内存 | 4 GB |
| 带宽 | 5 Mbps |
| 系统 | Linux (Ubuntu/CentOS) |
