## Docker 重装失败（14:40）

**问题**：Docker Desktop v4.74.0 已安装到 `D:\Docker`，CLI 可用（v29.4.3），但 **引擎无法启动**

**根因**：**BIOS 虚拟化未开启**（VT-x 未启用）
- WSL2 报错：`HCS_E_HYPERV_NOT_INSTALLED` + "此计算机上未启用虚拟化"
- 虚拟机平台 VirtualMachinePlatform 已启用，但硬件层面虚拟化被 BIOS 关闭
- 尝试切 WSL1 变通：Ubuntu 已注销，但 `wsl --install -d Ubuntu` 因 GitHub 国内访问超时失败

**解决方案**：需进 BIOS 开启 Intel VT-x / AMD SVM，或临时打开 VPN 重装 Ubuntu WSL1
