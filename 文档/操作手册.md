## 1. 环境要求

### 最低要求（核心服务）

| 软件 | 版本 | 用途 |
|------|------|------|
| Docker Desktop | 最新版 | 容器运行环境 |
| 内存 | ≥ 4GB | 分配 2GB 给 Docker |
| 硬盘 | ≥ 10GB 可用 | 项目代码 + Docker 镜像 |

### 完整服务（含 AI 检测）

| 软件 | 用途 |
|------|------|
| Docker Desktop | 同上 |
| 内存 ≥ 8GB | 含 AI 模型加载 |
| 硬盘 ≥ 20GB | 含 AI 模型权重 |

> **不需要** 安装 Java、Node.js、Python、MySQL、PyTorch、CUDA
> 全部环境由 Docker 容器提供

## 2. 快速启动（推荐）

### 第一步：获取代码

```bash
git clone https://gitee.com/sdu_-fzkx/456.git SafeGuard
cd SafeGuard
```

### 第二步：配置环境变量（可选）

```bash
cp .env.example .env
```

不配置 API Key 也能启动，但以下功能会使用降级模式：

| 未配置项 | 影响 | 降级策略 |
|----------|------|----------|
| 全部不配置 | 核心系统正常运行 | ✅ 后台管理、知识库、RAG 全部可用 |
| `DEEPSEEK_API_KEY` | AI 对话分析 | 返回预设分析结果 |
| `SILICONFLOW_API_KEY` | 向量嵌入 | 哈希生成嵌入向量 |
| `WECHAT_APPID/SECRET` | 微信登录 | 返回测试 token |

### 第三步：启动（三选一）

```bash
# 选项 A：只跑核心（推荐低配机器）
docker compose up -d

# 选项 B：核心 + AI 检测（需 8GB+）
docker compose --profile ai up -d

# 选项 C：全部服务（含前端 SPA）
docker compose --profile ai --profile web up -d
```

### 第四步：验证启动

```bash
# 查看启动日志
docker compose logs -f backend

# 等出现 "Started SafeGuardApplication" 后，打开浏览器：
# http://localhost:8080/api/health      → 后端健康检查
# http://localhost:8085                 → Vue 管理后台（仅 --profile web）
```

> 首次启动需要下载 Docker 镜像并编译后端，约 **5-15 分钟**，取决于网络。
> 后续启动只需 **10-30 秒**。

## 3. 分步部署选项

### 3.1 只有核心（日常使用）

```bash
docker compose up -d
```

启动 3 个服务：

| 服务 | 端口 | 用途 |
|------|------|------|
| MySQL 8.0 | 3307 | 数据持久化 |
| Qdrant | 6333 | 向量检索 |
| Spring Boot | 8080 | 后端 API + 管理后台 |

**管理后台**：核心服务只启动后端 API；如需 Vue 管理后台，请使用 `--profile web` 后访问 http://localhost:8085。

### 3.2 核心 + AI 检测

```bash
docker compose --profile ai up -d
```

额外启动 2 个服务：

| 服务 | 端口 | 用途 | 内存 |
|------|------|------|------|
| 音频检测 (Wav2Vec2) | 5000 | 语音伪造检测 | ~1GB |
| 视频检测 (XceptionNet) | 5002 | 视频换脸检测 | ~1GB |

### 3.3 全部服务

```bash
docker compose --profile ai --profile web up -d
```

额外启动前端 SPA：

| 服务 | 端口 | 用途 |
|------|------|------|
| Vue.js SPA | 8085 | 管理后台（独立前端） |

## 4. 本地开发（无 Docker）

如果不想用 Docker，也可以直接在本地运行。

### 4.1 前提条件

- Java 17+
- Node.js 22+
- Python 3.11+
- MySQL 8.0+（本地安装并运行）

### 4.2 数据库初始化

```bash
# 连接本地 MySQL
mysql -u root -p

# 执行建表脚本
mysql> source backend/src/main/resources/sql/schema.sql
mysql> source backend/src/main/resources/sql/init-data.sql

# 或者直接用 Spring Boot 自动初始化（配置已就绪）
```

### 4.3 启动服务

Windows 用户双击：
```
scripts/启动-本地开发服务.bat
```

或手动逐个启动：

```bash
# 终端 1：后端
cd backend && mvn spring-boot:run

# 终端 2：Web 管理后台
cd web-admin && npm install && npm run dev

# 终端 3：音频服务
cd ai-services/audio && python app.py

# 或统一启动音频+视频
cd ai-services && python run.py
```

### 4.4 访问地址

| 服务 | 地址 |
|------|------|
| 后端 API | http://localhost:8080 |
| 后端健康检查 | http://localhost:8080/api/health |
| 前端 Dev | http://localhost:5173 |
| 音频检测 | http://localhost:5000 |
| 视频检测 | http://localhost:5002 |

## 5. 管理后台使用

### 5.1 访问方式

- **Vue.js SPA**（Docker `--profile web`）：http://localhost:8085
- **Vue.js Dev Server**（本地开发）：http://localhost:5173

### 5.2 登录

系统**无默认管理员账号**。首次使用流程：

1. 浏览器打开 `http://localhost:8085` 或本地开发地址 `http://localhost:5173` 进入登录页
2. 切换到 **"注册管理员"** 标签
3. 填写用户名、昵称、密码（≥ 6 位）
4. 点击「注册」按钮，提示"注册成功"后自动跳转到登录模式
5. 用刚注册的用户名密码登录

> 后续可继续创建更多管理员账号。所有管理员共用同一套管理权限。

### 5.3 功能页面

| 页面 | Vue 路径 | 说明 |
|------|---------|------|
| 概览 | `/dashboard` | 系统统计、检测趋势图表（来自 detection_record 真实聚合） |
| 用户管理 | `/users` | 微信小程序用户列表（OpenID 脱敏展示） |
| 知识库管理 | `/knowledge` | 反诈知识条目管理 |
| 检测记录 | `/records` | 音频检测记录查看 |
| 模型管理 | `/models` | AI 模型版本管理 |
| 个人中心 | `/profile` | 修改个人信息、查看登录历史、修改密码 |

## 6. 常用命令

```bash
# 查看服务状态
docker compose ps

# 查看某个服务的日志
docker compose logs -f backend
docker compose logs -f qdrant

# 重新构建（代码更新后）
docker compose build
docker compose up -d

# 停止全部
docker compose down

# 清除全部数据（慎用，会丢失数据库和向量数据）
docker compose down -v
```

## 7. 常见问题

### Q: 启动报 "Port 8080 already in use"

本地有其他程序占用了 8080 端口。修改 `application.yml` 中的 `server.port` 换个端口。

### Q: Docker 拉取镜像很慢

配置国内镜像加速（Docker Desktop → Settings → Docker Engine → 添加）：

```json
{
  "registry-mirrors": [
    "https://docker.mirrors.ustc.edu.cn",
    "https://hub-mirror.c.163.com"
  ]
}
```

### Q: 需要重新初始化数据库

```bash
# 删除 MySQL 数据卷后重新启动即可
docker compose down -v
docker compose up -d
```

### Q: 前端页面白屏 / 接口 404

确认后端已经启动完成（日志出现 `Started SafeGuardApplication`），前端通过 `/api/` 路径访问后端，不需要额外配置代理。

### Q: 登录页点击"注册"提示失败

检查：
1. 后端日志：是否抛出 `404` 或数据库错误。`/api/auth/admin/register` 端点存在于最新版本。
2. 用户名是否已存在（注册逻辑会去重）。
3. 密码长度是否 ≥ 6 位。

### Q: Dashboard 趋势图/饼图是真实数据吗？

是。后端 `AdminController.getTrendStats` 从 `detection_record` 表按 `DATE(created_at)` + `result` 分组聚合，缺失日期补 0；饼图从 `countGroupByResultWithPercentage` 读取。

### Q: 用户列表中的 OpenID 为什么只显示前 4 后 4？

为保护用户隐私，前端 `Users.vue` 中 `maskOpenid()` 函数对 OpenID 进行脱敏。鼠标悬停时可通过 tooltip 查看完整值。

### Q: AI 助手一直显示"AI 服务暂时不可用"

1. 检查 `application.yml` 中 `llm.api-key` 是否已配置（DeepSeek / SophNet）。
2. 配置后可调用 `/api/llm/analyze/stream` 流式接口，浏览器使用 SSE 接收增量。
3. 若未配置 API Key，AI 助手会返回降级提示而非崩溃。

### Q: 不想启动某个服务

Docker Compose 支持按需启动：

```bash
# 只启动数据库和后端（跳过 Qdrant）
docker compose up -d db backend

# 只启动 AI 服务
docker compose --profile ai up -d
```

### Q: MySQL 连接失败（本地开发）

确保 MySQL 已启动，且 `application.yml` 中的用户名密码与本地一致。
本地 MySQL 默认密码为空时，将 `password: root123` 改为 `password: ""`。
