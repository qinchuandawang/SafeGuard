# 博客5：AI 音频伪造检测模块 — 从模型训练到前后端对接

## 一、概述

反诈系统需要应对的不只是文本诈骗。随着 AIGC 技术的发展，**AI 语音合成（语音克隆）** 已成为诈骗分子的新工具——只需几秒钟的语音样本，就能克隆出与目标高度相似的声音，冒充亲友或领导进行诈骗。

本博客详细记录 SafeGuard 项目中 **音频伪造检测模块** 的完整实现过程，包括：

- Wav2Vec2 模型的训练与推理
- Flask 检测服务的构建与优化
- 与 Spring Boot 后端的对接
- 与微信小程序前端的连通
- 全链路数据流

## 三、模型选择：Wav2Vec2

### 3.1 为什么选择 Wav2Vec2

| 方案 | 说明 | 优势 | 劣势 |
|------|------|------|------|
| **Wav2Vec2** | Facebook AI 自监督语音模型 | 预训练+微调效果好，ASVspoof 比赛 SOTA 之一 | 模型较大（~360MB），推理稍慢 |
| RawNet2 | 端到端音频深度伪造检测 | 轻量级 | 数据集依赖强 |
| LC-DNN | 传统方法 | 速度快 | 精度不如深度学习 |
| ResNet (频谱图) | 将音频转为频谱图后用 CNN | 可迁移图像分类技术 | 需要额外转换步骤 |

最终选择了 **Wav2Vec2**，它在 ASVspoof2019 LA 数据集上取得了优异的 EER（等错误率），且有 HuggingFace transformers 生态支持，便于集成。

### 3.2 模型结构

```
输入音频 (16kHz, 最大4秒)
    │
    ▼
┌─────────────────────┐
│   特征编码器 (CNN)    │  ← 7层卷积，提取频谱特征
│   conv_dim=[512*7]  │
└─────────┬───────────┘
          │
          ▼
┌─────────────────────┐
│   Transformer × 12  │  ← 自注意力机制，捕获时序依赖
│   hidden_size=768   │
└─────────┬───────────┘
          │
          ▼
┌─────────────────────┐
│   分类头 (Linear)    │  ← 2分类: bonafide(真实)/spoof(伪造)
│   num_labels=2      │
└─────────┬───────────┘
          │
          ▼
   {bonafide, spoof}
   + 伪造概率
```

## 四、训练模块

### 4.1 数据集：ASVspoof2019 LA

采用 **ASVspoof2019 Logical Access (LA)** 数据集，这是业界标准的音频深度伪造检测基准数据集。

| 子集 | 音频数 | 用途 |
|------|--------|------|
| train | 25,380 | 训练分类头 |
| dev | 24,986 | 调参和模型选择 |
| eval | 71,933 | 最终评估 |

**协议文件格式：**
```
LA_0079 LA_T_1138215 - A07 spoof
LA_0086 LA_D_1047731 - - bonafide
```

**下载方式：**
```bash
# 方式一：自动下载
python src/download_dataset.py --auto

# 方式二：手动下载
# 从 https://datashare.ed.ac.uk/handle/10283/3336 获取 LA.zip
python src/download_dataset.py --extract
```

### 4.2 训练命令

```bash
# 最小规模测试（快速验证流程）
python src/train_wav2vec2.py \
  --data_dir data \
  --model_dir pretrained/wav2vec2-base \
  --output_dir outputs/wav2vec2-minimal1 \
  --max_train_samples 64 \
  --max_dev_samples 16 \
  --epochs 1 \
  --batch_size 4 \
  --lr 1e-5

# 完整训练（推荐）
python src/train_wav2vec2.py \
  --data_dir data \
  --model_dir pretrained/wav2vec2-base \
  --output_dir outputs/wav2vec2-full \
  --epochs 3 \
  --batch_size 8 \
  --fp16 \
  --use_class_weight
```

### 4.3 训练流程

```
1. 加载预训练 Wav2Vec2ForPreTraining
                    ↓
2. 替换分类头 → Wav2Vec2ForSequenceClassification (num_labels=2)
                    ↓
3. 冻结特征提取器（CNN 层）
                    ↓
4. 仅训练 Transformer + 新分类头
                    ↓
5. 输出最佳模型到 outputs/xxx/best/
```

## 五、推理服务

### 5.1 核心推理流程

```
用户上传音频 (.wav/.flac/.mp3/.ogg)
    │
    ▼
┌─────────────────────────────────────┐
│ 1. 音频加载 (utils.load_audio)      │
│    └ 多声道→单声道                   │
│    └ FFT重采样→16kHz                 │
│    └ 截断→最大4秒                     │
└──────────────┬──────────────────────┘
               ▼
┌─────────────────────────────────────┐
│ 2. Processor 特征提取               │
│    └ Wav2Vec2Processor              │
│    └ padding→统一长度                │
│    └ return_tensors="pt"            │
└──────────────┬──────────────────────┘
               ▼
┌─────────────────────────────────────┐
│ 3. Wav2Vec2 模型推理                │
│    └ model → logits                 │
│    └ softmax → probs                │
│    └ argmax → label                 │
└──────────────┬──────────────────────┘
               ▼
┌─────────────────────────────────────┐
│ 4. 结果组装                         │
│    ├ label: "bonafide" / "spoof"    │
│    ├ spoof_prob: 0.985              │
│    ├ bonafide_prob: 0.015           │
│    ├ confidence: 0.985              │
│    ├ risk_level: "high"             │
│    └ latency_ms: 123.45             │
└─────────────────────────────────────┘
```

### 5.2 风险评估规则

| 伪造概率 | 风险等级 | 说明 |
|----------|----------|------|
| ≥ 0.85 | high | 高度疑似AI伪造 |
| ≥ 0.50 | medium | 部分可疑特征 |
| < 0.50 | low | 未检测到明显伪造 |

### 5.3 线程安全设计

Flask 服务默认使用多线程处理请求，模型加载部分使用**双重检查锁定**避免竞态条件：

```python
_model_lock = threading.Lock()

def load_model_once(model_dir):
    if _model_loaded:
        return PROCESSOR, MODEL
    with _model_lock:
        if _model_loaded:  # 双重检查
            return PROCESSOR, MODEL
        # 实际加载模型...
        PROCESSOR = Wav2Vec2Processor.from_pretrained(str(model_dir))
        MODEL = Wav2Vec2ForSequenceClassification.from_pretrained(...)
        _model_loaded = True
```

### 6.4 前端音频结果处理

前端 `detection.js` 新增 `normalizeAudioResult()` 方法，将后端返回的音频检测结果标准化为统一的展示格式：

```javascript
normalizeAudioResult(raw) {
  // 解析后端返回的 AudioDetectionResult
  const spoof = raw.spoofProb || 0.5;
  const bonafide = raw.bonafideProb || (1 - spoof);
  
  return {
    type: 'audio',
    confidence: raw.confidence || 0.7,
    label: raw.label || 'unknown',
    riskLevel: raw.riskLevel || 'unknown',
    spoofProb: spoof,
    bonafideProb: bonafide,
    probabilities: { real: bonafide, fake: spoof },
    // 根据风险等级生成报告和建议
    report: '...',
    advice: ['不要轻信音频内容', '通过其他渠道核实', ...],
    agentSteps: [...]  // 展示检测流程步骤
  };
}
```

## 七、数据库持久化

对接过程新增了 3 张数据库表用于持久化检测记录：

| 表名 | 用途 | 关键字段 |
|------|------|----------|
| `audio_detection_record` | 音频检测记录 | task_id, file_name, detection_result, spoof_probability, risk_level, model_version |
| `detection_record` | 综合检测记录 | task_id, detection_type, status, result, risk_score |
| `audio_model` | 音频模型信息 | name, model_version, model_type, accuracy, eer, is_active |

使用 **MyBatis-Plus** 替代原有的 JPA，Mapper 接口使用注解 SQL：

```java
@Mapper
public interface AudioDetectionRecordMapper extends BaseMapper<AudioDetectionRecord> {
    @Select("SELECT * FROM audio_detection_record WHERE task_id = #{taskId} AND deleted = 0")
    AudioDetectionRecord findByTaskId(@Param("taskId") String taskId);
    
    @Select("SELECT COUNT(*) FROM audio_detection_record WHERE detection_result = #{result} AND deleted = 0")
    long countByDetectionResult(@Param("result") String result);
}
```

## 九、关键技术决策

### 9.1 架构选择：独立 Flask 服务 vs Java 直接加载模型

| 方案 | 说明 | 选择理由 |
|------|------|----------|
| ✅ **独立 Flask 服务** | Python 运行模型推理，Java 通过 HTTP 调用 | Python 的 AI 生态成熟（PyTorch/HuggingFace） |
| ❌ Java 直接加载 | 用 ONNX Runtime / DJL 在 Java 中推理 | 模型转换复杂，调试困难 |

### 9.2 音频重采样方法

| 方法 | 质量 | 速度 | 依赖 |
|------|------|------|------|
| **FFT 重采样** (scipy.signal.resample) | ⭐⭐⭐ 高 | 中等 | scipy |
| 线性插值 (np.interp) | ⭐⭐ 中等 | 快 | 无 |

代码自动检测 scipy 是否可用，优先使用 FFT 重采样，否则降级为线性插值。

### 9.3 模型加载容错

```python
# 自动降级机制
MODEL_DIR = Path("outputs/wav2vec2-mid/best")    # 首选路径
FALLBACK_MODEL_DIR = Path("pretrained/wav2vec2-base")  # 备选演示路径

# 若首选路径不存在，自动使用 pretrained 模型演示
```

### 9.4 数据库持久化方案

| 方案 | 说明 |
|------|------|
| ORM | MyBatis-Plus（替代原 JPA） |

| 表结构 | 4 张核心表：knowledge_item, audio_detection_record, detection_record, audio_model |
