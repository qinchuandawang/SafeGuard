# SafeGuard 音频训练模块 — 使用指南

> 项目结构自 v2.0 起重构，所有 Python 源码统一置于 `src/` 目录。
> 所有命令请在 `audio-training/` 根目录执行。

---

## 环境准备

```bash
# 1. 安装 Python 依赖
python -m pip install -r requirements.txt

# 2. 下载训练数据集 ASVspoof2019 LA（约 7.3GB）
#    下载地址: https://datashare.ed.ac.uk/handle/10283/3336
python src/download_dataset.py --auto

#    或手动下载 LA.zip 放入 data/ 后解压:
python src/download_dataset.py --extract

# 3. 验证数据集完整性
python src/download_dataset.py --verify
```

## 训练命令

### 最小规模测试（快速验证）
```bash
python src/train_wav2vec2.py \
    --data_dir data \
    --model_dir pretrained/wav2vec2-base \
    --output_dir outputs/wav2vec2-minimal1 \
    --max_train_samples 64 --max_dev_samples 16 \
    --epochs 1 --batch_size 4 --lr 1e-5 \
    --weight_decay 0.01 --warmup_ratio 0.1 \
    --save_total_limit 2 --use_class_weight \
    --num_workers 4 \
    --eval_strategy epoch --save_strategy epoch --logging_steps 10
```

### 中规模（推荐）
```bash
python src/train_wav2vec2.py \
    --data_dir data \
    --model_dir pretrained/wav2vec2-base \
    --output_dir outputs/wav2vec2-mid \
    --max_train_samples 2000 --max_dev_samples 500 \
    --epochs 3 --batch_size 8 --lr 1e-5 \
    --weight_decay 0.01 --warmup_ratio 0.1 \
    --save_total_limit 2 --use_class_weight \
    --metric_for_best_model f1 \
    --num_workers 8 \
    --eval_strategy epoch --save_strategy epoch --logging_steps 20 --fp16
```

### 全规模（完整训练）
```bash
python src/train_wav2vec2.py \
    --data_dir data \
    --model_dir pretrained/wav2vec2-base \
    --output_dir outputs/wav2vec2-full \
    --epochs 3 --batch_size 8 \
    --grad_accum_steps 1 --lr 1e-5 \
    --weight_decay 0.01 --warmup_ratio 0.1 \
    --decision_threshold 0.5 \
    --save_total_limit 2 --use_class_weight \
    --metric_for_best_model f1 \
    --num_workers 8 \
    --eval_strategy epoch --save_strategy epoch --logging_steps 50 --fp16 --seed 42
```

## 推理命令

### 单条推理
```bash
python src/infer_audio.py \
    --model_dir outputs/wav2vec2-mid/best \
    --audio_path data/ASVspoof2019_LA_dev/flac/LA_D_1047731.flac
```

### 批量推理（仅推理）
```bash
python src/infer_audio_batch.py \
    --model_dir outputs/wav2vec2-mid/best \
    --audio_dir data/ASVspoof2019_LA_dev/flac \
    --glob "*.flac" \
    --output_csv outputs/dev_batch_results.csv
```

### 批量推理 + 评估
```bash
python src/infer_audio_batch.py \
    --model_dir outputs/wav2vec2-mid/best \
    --audio_dir data/ASVspoof2019_LA_dev/flac \
    --glob "*.flac" \
    --protocol_path "data/ASVspoof2019_LA_cm_protocols/ASVspoof2019.LA.cm.dev.trl.txt" \
    --output_csv outputs/dev_batch_results.csv
```

### 阈值扫描
```bash
python src/threshold_scan.py \
    --input_csv outputs/dev_batch_results.csv \
    --thresholds "0.35,0.4,0.45,0.5,0.55,0.6" \
    --optimize_for f1_spoof \
    --output_csv outputs/threshold_scan_results.csv
```

## Flask 服务

启动检测服务（默认端口 5000）:
```bash
python src/app.py
```

自定义模型路径:
```bash
set MODEL_DIR=pretrained/wav2vec2-base
python src/app.py
```

自定义端口:
```bash
set PORT=8080
python src/app.py
```

|------|------|------|
| GET | `/` | 服务信息 |

## 数据集下载说明

- **数据集**: ASVspoof2019 Logical Access (LA)
- **大小**: 约 7.3GB（压缩包）
- **下载地址**: https://datashare.ed.ac.uk/handle/10283/3336

## 常见问题

1. **模型加载失败**: 确保 `pretrained/wav2vec2-base` 目录完整
2. **训练时 OOM**: 减小 `--batch_size` 或启用 `--fp16`
3. **Windows 路径问题**: 使用绝对路径或确保在项目根目录执行命令
