# SafeGuard 音频训练 — 运行总结

**日期**: 2026-05-21  
**环境**: Python 3.11 + PyTorch 2.6.0 (CUDA 12.4) + RTX 4060 Laptop GPU

## 1. 模型训练

### 命令

```bash
python src/train_wav2vec2.py \
  --data_dir data \
  --model_dir pretrained/wav2vec2-base \
  --output_dir outputs/demo-run \
  --max_train_samples 64 \
  --max_dev_samples 16 \
  --epochs 1 \
  --batch_size 1 \
  --lr 1e-5 \
  --num_workers 0
```

### 训练过程

| 指标 | 值 |
|------|------|
| 训练样本 | 64 |
| 验证样本 | 16 |
| 训练轮数 | 1 epoch |
| 总耗时 | 9.6s |
| 最终 train loss | 0.5369 |

Loss 变化: 0.6929 → 0.6603 → 0.5905 → ... → 0.3303（稳步下降）

### 验证指标

| 指标 | 值 |
|------|------|
| eval_loss | 0.4932 |
| eval_accuracy | **81.25%** |
| eval_f1_spoof | 0.8966 |
| eval_precision_spoof | 0.8125 |
| eval_recall_spoof | 1.0 |
| eval_f1_bonafide | 0.0 |

> **说明**: 仅用 64 个样本训练，模型严重偏向 spoof 类别（dev 集 16 样本中 13 个 spoof / 3 个 bonafide），导致 bonafide F1=0。完整训练（25380 样本）可大幅改善。

## 2. 较大规模训练

### 命令

```bash
python src/train_wav2vec2.py \
  --data_dir data \
  --model_dir pretrained/wav2vec2-base \
  --output_dir outputs/demo-large \
  --max_train_samples 5000 \
  --max_dev_samples 1000 \
  --epochs 3 \
  --batch_size 1 \
  --lr 1e-5 \
  --use_class_weight \
  --fp16 \
  --num_workers 0
```

### 训练过程

| 指标 | 值 |
|------|------|
| 训练样本 | 5000（20% 数据集） |
| 验证样本 | 1000 |
| 训练轮数 | 3 epochs |
| 总耗时 | 2418s（~40 分钟） |
| 最终 train loss | 0.09025 |
| 吞吐量 | 6.2 samples/s |

> 类别权重: bonafide=4.81, spoof=0.56（数据集 90% 为 spoof）

### 逐 Epoch 验证指标

| 指标 | Epoch 1 | Epoch 2 | Epoch 3 |
|------|---------|---------|---------|
| eval_loss | 0.09121 | 0.00696 | **3.86e-05** |
| accuracy | 97.7% | 99.9% | **100%** |
| f1_spoof | 0.9871 | 0.9994 | **1.0** |
| precision_spoof | 1.0 | 0.9989 | **1.0** |
| recall_spoof | 0.9744 | 1.0 | **1.0** |
| f1_bonafide | 0.8969 | 0.995 | **1.0** |
| precision_bonafide | 0.813 | 1.0 | **1.0** |
| recall_bonafide | 1.0 | 0.99 | **1.0** |

### 混淆矩阵（Epoch 3）

## 3. 单条音频推理

使用三个模型对比推理结果。

### 模型对比

| 模型 | 训练样本 | Spoof 预测 (LA_D_1000265) | Bonafide 预测 (LA_D_1047731) |
|------|---------|--------------------------|----------------------------|
| **demo-large** | **5000** | spoof ✅ 99.999% (high) | **bonafide ✅ 99.998%** (low) |
| demo-run | 64 | spoof ✅ 73.7% (medium) | spoof ❌ 74.1% (medium) |
| wav2vec2-run | 25380 | spoof ✅ 65.8% (medium) | spoof ❌ 66.7% (medium) |

> **demo-large 模型在两类测试音频上均正确识别，置信度高达 99.998%+。** 相比之下，仅 64 样本训练的模型和旧版全量模型均对所有样本预测为 spoof。

### demo-large 推理详情

| 测试文件 | 真实标签 | 预测标签 | spoof_prob | bonafide_prob | 风险等级 | 延迟 |
|---------|---------|---------|-----------|-------------|---------|------|
| LA_D_1000265.flac | **spoof** | spoof ✅ | 99.999% | 0.001% | high | 662ms |
| LA_D_1047731.flac | **bonafide** | bonafide ✅ | 0.002% | 99.998% | low | 346ms |

> 推理延迟为首次加载（含模型加载），后续推理 < 350ms。
