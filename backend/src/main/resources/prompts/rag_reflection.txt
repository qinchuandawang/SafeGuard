【用户问题】
{query}

【已检索到的知识摘要】
{knowledge}

请只输出一个合法 JSON 对象，不要 Markdown，不要代码块：
{
  "sufficient": true 或 false,
  "missingFacets": ["缺失的知识面1", "缺失的知识面2"]
}

判断规则：
1. sufficient=true 表示现有知识已能支撑回答该问题。
2. 只有当现有知识明显缺失关键诈骗类型、止损流程或核验方法时，才在 missingFacets 中列出缺失面。
3. missingFacets 使用用户可理解的关键词短语，例如"刷单止损流程"、"公检法核验渠道"。
4. 知识充分时 missingFacets 必须为空数组。
